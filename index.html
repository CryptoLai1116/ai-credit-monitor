      FRAMEWORK

      我們不是只看 CDS

      儀表板將信用價格分成三層：整體信用市場、AI 產業信用、公司個別信用。只有當資金價格惡化進一步傳導至新債發行、替代融資與實際專案時，才判定為「融資受限」。

      IMPORTANT LIMITATION

      CDS 與即時債券資料可能需要授權

      公開網站通常無法提供完整即時 CDS、TRACE、asset-swap spread 或新債訂單簿。本網站預留資料介面，但未接 Bloomberg、LSEG、ICE 或其他授權 API 時，數值應視為研究框架或人工更新欄位。
